# 智绘脑图 SmartBrainMap — 启动指南

本目录（`.claude\`）内的 `start.bat` 是**一键启动脚本**，下面说明它的使用方法，以及**不用脚本时的手动启动方法**。

---

## 一、文件说明

| 文件 | 作用 |
|---|---|
| `.claude\start.bat` | 一键启动脚本（双击即可） |
| `.claude\stop.bat` | 一键停止脚本（双击即可停掉后端服务） |
| `.claude\启动说明.md` | 本说明文档 |

> 脚本依赖项目根目录下的 `.venv` 虚拟环境（首次运行需先安装依赖，见第三节）。数据库使用 SQLite，数据保存在项目根的 `backend\app.db`，**不会因重启而丢失**。

---

## 二、使用 `start.bat`（推荐）

### 方法 1：双击运行
在文件管理器里进入 `源码\源码\.claude\`，**双击 `start.bat`**。
脚本会自动：
1. 切换到项目根目录；
2. 检查 `.venv` 是否就绪；
3. 检测端口 8000 是否被占用（占用会提示并退出，防止重复启动）；
4. 自动打开浏览器 `http://127.0.0.1:8000/login.html`；
5. 在前台启动后端服务。

**停止服务**：关掉命令行窗口，或在该窗口按 `Ctrl + C`。

### 方法 2：命令行运行
```bash
# 在任意位置
"E:\学校相关\比赛类\大二\大二上\2027年数媒计设大赛\源码\源码\.claude\start.bat"
```

### 启动成功后
浏览器打开 **`http://127.0.0.1:8000/login.html`** 即可体验。

可用账号：

## 三、停止服务

### 方法 1：一键停止（推荐）
双击 `.claude\stop.bat`，脚本会自动找到占用 8000 端口的后端进程并结束它。
> 如果提示"未检测到占用 8000 端口的服务"，说明后端本来就没在运行，可放心忽略。

### 方法 2：启动窗口还开着
在启动后端的黑色 cmd 窗口里按 `Ctrl + C`，看到"服务已停止"后关掉窗口。

### 方法 3：窗口关了但服务还在后台
用任务管理器结束对应的 python 进程，或在命令行执行：
```bash
for /f "tokens=5" %p in ('netstat -ano ^| findstr ":8000" ^| findstr LISTENING') do taskkill /F /PID %p
```

## 四、不用脚本 —— 手动启动

### 情况 A：依赖已装好（日常只需两步）
```bash
cd "E:\学校相关\比赛类\大二\大二上\2027年数媒计设大赛\源码\源码"
.venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```
看到 `Uvicorn running on http://127.0.0.1:8000` 即成功，浏览器打开 `http://127.0.0.1:8000/login.html`。

### 情况 B：从零开始 / 换电脑 / 环境被清（完整流程）
```bash
# 1. 进项目根目录
cd "E:\学校相关\比赛类\大二\大二上\2027年数媒计设大赛\源码\源码"

# 2. 创建虚拟环境（需要 Python 3.11）
python -m venv .venv

# 3. 安装依赖（⚠️ 必须用清华镜像，本机 pypi 官方源 SSL 校验会失败）
.venv\Scripts\python -m pip install -r requirements.txt ^
  -i https://pypi.tuna.tsinghua.edu.cn/simple ^
  --trusted-host pypi.tuna.tsinghua.edu.cn

# 4. 配置 .env（若 backend\.env 不存在）
copy backend\.env.example backend\.env
# 然后用编辑器打开 backend\.env，把 DATABASE_URL 改成：
#   DATABASE_URL=sqlite:///./backend/app.db

# 5. 启动（建表会在启动时自动完成，无需手动建）
.venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 启动报 `address already in use` / 脚本提示端口被占用 | 说明已有服务在跑。直接访问 `http://127.0.0.1:8000/login.html` 即可；要重启就先用任务管理器关掉占用 8000 的 python 进程 |
| `pip install` 报 `SSL: CERTIFICATE_VERIFY_FAILED` | 用清华镜像（见第三节第 3 步），不要用默认源 |
| 页面打开但接口报错 | 确认后端命令行窗口里有 `Uvicorn running`；务必用 `http://127.0.0.1:8000/xxx.html` 访问，**不要双击 html（file:// 会被浏览器安全策略拦截）** |
| 影像预测接口返回 503 | 属正常：`/model/predict_fmri` 需要 torch+dhg（Python≤3.10），本机 3.11 装不了。其它功能不受影响 |
| AI 助手回复是"本地辅助模式" | 正常：没配 `QWEN_API_KEY`，走模板回退。要接真模型就在 `backend\.env` 填 `QWEN_API_KEY` |
| 忘了之前的测试数据 | 数据都在 `backend\app.db`；删掉该文件再启动即恢复"全新"状态 |
