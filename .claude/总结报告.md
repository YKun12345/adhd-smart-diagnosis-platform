## 一、项目全貌

智绘脑图 SmartBrainMap 是一个面向全年龄段执行功能(以 ADHD 为主)的纵向筛查与图谱评估的多模态数字医疗平台。整体架构如下:

- `*.html` + `js/` + `css/`:前端 H5 页面
- `miniprogram/`:微信小程序(目前是 login / home 两页脚手架)
- `backend/`:FastAPI 后端,已完整可用
- `HGST-main/`:脑影像图神经网络 GNN 模块
- `findviz/` 及 `tools/patch_*`:脑功能连接可视化工具

**A/B 分工**:A 负责前端(H5 + 小程序),B 负责后端(FastAPI)。

## 五、`.claude` 文件夹中各文档说明

`.claude/` 是项目研发协作的工作台,里面的文件如下:

| 文件 / 目录 | 用途 |

| `CLAUDE_skill_readme.md` | 说明本项目的 Claude skill(技能)约定,和编码指导原则 |
| `progress.md` | 项目进度记录,B 逐次追加,按时间推进 |
| `tasks.md` | B 工程师任务规划(21 项)+ 拆分及状态 |

| `Git协作规范.md` | 仓库初始化,分支策略 / commit 规范 / 分工约定 / 常用流程 / 禁忌 |
| `启动说明.md` | 一键 start.bat / stop.bat 的用法,和手动启动方式 |
| `start.bat` | 一键启动脚本(自动启动后端并打开浏览器) |
| `stop.bat` | 一键停止脚本(自动结束占用 8000 的后端进程) |
| `settings.local.json` | 本地 Claude Code 的权限配置,不属于业务代码 |
| `logs/` | 预留目录(当前为空) |
| `reports/` | 预留目录(当前为空) |
| `scripts/` | 后端验证 / 联调脚本。里面是 `verify_*.py` 与 `integration_test.py`、`reset_patient_password.py` |
